# Omarchy on this Mac

Caps Lock: hold = Super, tap = Escape. Super+K lists every shortcut; Super+Space opens the menu.

- Every shortcut: KEYBINDINGS.md (generated from bindings.toml)
- Change a shortcut: edit ~/.config/omarchy-mac/bindings.toml, then `omarchy-keys check && omarchy-keys install`
- Health check: `omarchy-doctor --static` (guided key test: `--interactive`, `--secure-input`)
- Theme: `omarchy-theme set <name>` or Super+Ctrl+T
- Undo everything: ~/.config/omarchy-mac/build/rollback.sh
